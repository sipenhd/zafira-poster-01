# ZAFIRA — The Sky Train Crosses the Dunes

A travel poster for a place that does not exist: **Zafira**, a desert
crossed by a sky train at sunset.

A huge low orange sun sinks behind rolling dunes while a long elevated
rail carries a little train of lit cars across the sky on slender
stilts. Below, a tiny station and a few travellers wait on the sand.
Warm plum-to-gold sky, soft clouds, birds, and a bold navy title band.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=<output dir> python3 main.py
```

`main.py` (pure Python 3 stdlib, no network, no input files) paints the
poster pixel-by-pixel and writes `/output/entry.png` (1024×1024).
